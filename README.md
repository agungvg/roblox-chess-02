Chess Brainrot Battle Royale: 48 chess pieces, 8 rarities, 8 mutations, 6 rival boards to capture from and lock against, Blitz Storm, Checkmate Rush, En Passant Raid, Golden Runaway, Night Raid, Tidal Wave, Piece Codex, rebirth — a 3D Roblox brainrot game where chess pieces parade, earn money per second, and get captured.

## Run it

```sh
rojo build default.project.json --output game.rbxl
```

Open `game.rbxl` in Roblox Studio to play it.
